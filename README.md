# Sổ tay số Nghệ An 2026

Học liệu bồi dưỡng năng lực số cho giáo viên THCS và THPT (tỉnh Nghệ An, 2026).

- 5 khóa: Nền chung, THCS KHXH, THCS KHTN, THPT KHXH, THPT KHTN
- 17 bài thực hành 10–25 phút, 6 công cụ tương tác, bộ 8 phiếu in A4
- Chạy hoàn toàn ngoại tuyến sau lần tải đầu

Bản công khai: https://ktzung.github.io/NAEM2026/
